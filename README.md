# altessa-s Scoop bucket

[Scoop](https://scoop.sh) manifests for the command-line tools of ALTESSA SOLUTIONS INC.

```powershell
scoop bucket add altessa-s https://github.com/altessa-s/scoop-bucket
scoop install rmctl
```

| App | Description |
|---|---|
| [rmctl](https://github.com/altessa-s/rmctl) | Command-line client for the reMarkable cloud |

The manifests in `bucket/` are written by each tool's release workflow; edits are overwritten.
